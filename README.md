Cripto Bank
Um sistema bancário de criptomoedas desenvolvido em linguagem C, que permite ao usuário gerenciar seu saldo em reais e realizar operações de compra e venda de criptomoedas.
O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de programação em C, como estruturas, funções, ponteiros, manipulação de arquivos e estruturas de repetição.

Funcionalidades
O sistema possui as seguintes funcionalidades:
Login: acesso utilizando CPF e senha.
Consultar saldo: visualização dos saldos em reais e criptomoedas.
Consultar extrato: histórico das operações realizadas.
Depositar reais: adicionar dinheiro à carteira.
Sacar reais: retirar dinheiro da carteira.
Comprar criptomoedas: comprar Bitcoin, Ethereum e Ripple.
Vender criptomoedas: vender criptomoedas e receber em reais.
Atualizar cotações: simulação de variação dos preços das criptomoedas.
Criptomoedas disponíveis

O sistema trabalha com três criptomoedas:
Bitcoin (BTC)
Ethereum (ETH)
Ripple (XRP)

As cotações iniciais são definidas no próprio programa e podem ser atualizadas com variações aleatórias entre -5% e +5%.
